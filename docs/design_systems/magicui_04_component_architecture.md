# Magic UI Principle 4: Component Independence (ความอิสระของคอมโพเนนต์)

## แนวคิดหลัก (Core Concept)
Magic UI ยึดหลักการออกแบบสไตล์ "Copy & Paste" คือทุกคอมโพเนนต์สามารถยืนหยัดได้ด้วยตัวเอง ไม่ผูกติดกับ Framework ใหญ่ๆ มากเกินไป

## กฎการออกแบบจาก Magic UI
1. **Self-contained Logic (ตรรกะในตัวเอง):**
   - โค้ดของปุ่ม (Button) โค้ดของการ์ด (Card) หรือโค้ดของช่องแชท ควรถูกแยกไฟล์กันอย่างเด็ดขาด (Modular)
   - หากต้องการแก้ไขสไตล์ของปุ่ม ต้องแก้ที่ไฟล์ปุ่มเท่านั้น ไม่กระทบกับไฟล์อื่นๆ
2. **Minimal Dependencies (พึ่งพาคนอื่นให้น้อยที่สุด):**
   - ใช้เครื่องมือพื้นฐานที่มีอยู่ให้เกิดประโยชน์สูงสุด แทนที่จะติดตั้งไลบรารีขนาดใหญ่มาเพียงเพื่อทำปุ่มเล็กๆ หนึ่งปุ่ม
3. **Customizability (การปรับแต่งได้ง่าย):**
   - ถึงแม้คอมโพเนนต์จะถูกออกแบบมาอย่างดีแล้ว แต่ก็ต้องเปิดช่องทางให้โปรแกรมเมอร์ปรับเปลี่ยน (Override) สี, ขนาด หรือฟอนต์ได้ง่ายๆ จากส่วนกลาง (เช่น `app/theme.py`)
