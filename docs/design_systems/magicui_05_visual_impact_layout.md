# Magic UI Principle 5: Visual Impact Layout (เลย์เอาต์ที่สร้างความประทับใจ)

## แนวคิดหลัก (Core Concept)
Magic UI โดดเด่นเรื่องการจัดวางเลย์เอาต์แบบ "ทำให้ผู้ดูตะลึง" (High Visual Impact) โดยเฉพาะสำหรับหน้าหลัก (Hero Section) และการแสดงข้อมูลหลายรายการในเวลาเดียวกัน

## กฎการออกแบบจาก Magic UI
1. **Bento Grid Pattern (การจัดวางแบบ Bento):**
   - แทนที่จะแสดงข้อมูลเป็นรายการตรงๆ (List) ให้ใช้กล่องหลายขนาดจัดเรียงคล้ายกล่องข้าว Bento เพื่อให้หน้าตา dynamic และดึงดูดสายตา
   - กล่องขนาดใหญ่กว่าคือข้อมูลที่สำคัญกว่า ทำให้ผู้ใช้เข้าใจลำดับความสำคัญได้ทันที
2. **Hero Section (ส่วนแนะนำที่โดดเด่น):**
   - หน้าจอแรกที่ผู้ใช้เห็นต้องสื่อสาร "จุดประสงค์ของแอปนี้คืออะไร" ได้ในพริบตา ด้วย Headline ขนาดใหญ่และ CTA (Call to Action) ที่ชัดเจน
3. **Animated Lists & Timelines (รายการที่มีชีวิต):**
   - เมื่อแสดงรายการข้อมูลหลายรายการ (เช่น Log ของหุ่นยนต์) การให้แต่ละรายการ "ค่อยๆ เลื่อนเข้ามา" (Stagger Animation) ทำให้ผู้ใช้ติดตามข้อมูลได้ง่ายขึ้น แทนที่ข้อมูลจะโผล่ขึ้นมาทั้งหมดพร้อมกัน
