# Magic UI Principle 3: High-Fidelity Details (รายละเอียดความคมชัดสูง)

## แนวคิดหลัก (Core Concept)
ส่วนเล็กๆ น้อยๆ ที่ประกอบกันเป็น UI (Micro-aesthetics) คือสิ่งที่แบ่งแยกระหว่างแอปทั่วไป กับแอประดับพรีเมียม (Premium Feel)

## กฎการออกแบบจาก Magic UI
1. **Glow & Gradients (แสงเรืองรองและการไล่สี):**
   - การใช้แสงเรืองรอง (Glow) สลัวๆ หลังปุ่มหลัก หรือหลังการ์ดสำคัญ เพื่อดึงดูดสายตาอย่างแยบยล
   - แทนที่จะใช้สีทึบสีเดียว อาจมีการไล่สี (Gradient) อ่อนๆ จากมุมหนึ่งไปอีกมุมหนึ่ง เพื่อให้พื้นผิวดูไม่แข็งทื่อ
2. **Subtle Borders (เส้นขอบที่บางเบา):**
   - กล่องหรือการ์ดทุกใบจะมีเส้นขอบ (Border) แต่เป็นขอบที่บางมากๆ (1px) และใช้สีที่อ่อนมาก (ใกล้เคียงกับสีพื้นหลัง) เพื่อทำหน้าที่แค่ "ตีกรอบ" แต่ไม่ "ขโมยความสนใจ"
3. **Rounded Corners (ความโค้งมน):**
   - ส่วนประกอบแทบทุกอย่างจะมีมุมโค้ง (Border-radius) ที่สม่ำเสมอ เพื่อลดความแข็งกระด้างของสี่เหลี่ยม และให้ความรู้สึกเป็นมิตรมากขึ้น
