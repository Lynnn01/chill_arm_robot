# Principle 1: Color System (ระบบสี)

## แนวคิดหลัก (Core Concept)
สีเป็นสิ่งแรกที่ผู้ใช้สังเกตเห็น การกำหนดระบบสีที่ชัดเจนช่วยสร้างเอกลักษณ์และลำดับความสำคัญของข้อมูล 

## กฎการออกแบบจาก Awesome Design Systems
1. **Primary & Secondary Colors (สีหลักและสีรอง):**
   - ควรกำหนดสีหลัก (Primary) เพียง 1-2 สีเพื่อใช้เป็นจุดสนใจ เช่น ปุ่มยืนยัน (Call to Action)
   - สีรอง (Secondary/Accent) ใช้สำหรับสร้างความน่าสนใจ หรือแบ่งแยกหมวดหมู่ข้อมูล
2. **Semantic Colors (สีที่มีความหมายสากล):**
   - **Success (สำเร็จ):** โทนสีเขียว
   - **Warning (เตือน):** โทนสีเหลือง/ส้ม
   - **Danger/Error (อันตราย/ข้อผิดพลาด):** โทนสีแดง
   - **Info (ข้อมูลทั่วไป):** โทนสีฟ้า
3. **Neutral Colors (สีโทนกลาง):**
   - สีดำ เทา และขาว ใช้สำหรับข้อความ พื้นหลัง และเส้นขอบ
   - ควรมีเฉดสีเทาหลายระดับ (เช่น Slate 50 ถึง Slate 900) เพื่อสร้างลำดับชั้นของพื้นหลังและตัวอักษร
4. **Contrast (ความเปรียบต่าง):**
   - สีของตัวอักษรต้องตัดกับสีพื้นหลังอย่างชัดเจน (เช่น ตัวอักษรสีดำบนพื้นขาว หรือตัวอักษรสีขาวบนปุ่มสีเข้ม) เพื่อให้อ่านง่าย
