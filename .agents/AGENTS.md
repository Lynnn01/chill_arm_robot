## ⚡ Critical Rules

### Important Side Effects and Safety Boundaries
- `tools.py` and `init.py` will create `MyCobot('/dev/ttyUSB0', 1000000)` upon import, and may trigger robotic arm initialization. When writing tests, scripts, or performing static checks later, avoid accidentally importing these modules.
- `grab_object` will take photos, call the external vision API, calculate coordinates, and drive the robotic arm to grasp.
- `move_to` and `show_object` will directly send robotic arm coordinate/angle commands.
- `ReactAgent.run_code_and_format_result` will execute Python code generated by the model. It is currently used to generate placement coordinates; when modifying, code execution risks and result format compatibility must be considered.
- There are external service addresses and hardcoded credentials in the project. Do not add, copy, or expose keys in commits, documentation, or logs; if adjustments are needed, prioritize changing to environment variables or local configurations.

### Collaboration Tips for Subsequent Agents
When taking over a task, first determine whether it will touch the hardware. If it's just modifying parsing, configuration, documentation, or pure tool functions, it can be handled on a normal development machine; if it involves executing robotic arm movements, first confirm with the user whether the real device is currently connected, whether movement is allowed, and whether the workspace is safe. Keep changes small and explicit during implementation, and finally explain which commands have been verified and which have not been verified due to a lack of hardware or network.
