# Project Overview

This project is a Python Robotic Arm Agent that combines a large language model, visual detection, a camera, and JetCobot/MyCobot hardware to complete tasks such as grasping, showing, and placing.

- Main entry: `agent.py`
  - Starts the interactive loop by default.
  - Currently uses keyboard input.
  - Initializes `RequestLLM`, `ReactAgent`, and registers tools.
- Command-line entry: `agent2.py`
  - Supports passing a single user instruction directly, and also supports `--interactive` / `--voice`.
  - Uses another set of LLM endpoint/model configurations.
- Tool implementation: `tools.py`
  - Hardware tools registered to ReAct Agent: `grab_object`, `move_to`, `show_object`.
  - Importing it will instantiate the robotic arm and execute initialization logic; handle with care.
- Agent Framework: `react_agent/`
  - `agent.py`: Parses `✿FUNCTION✿` / `✿ARGS✿` in the model output, executes tool calls; also executes Python code generated by the model and reads the global variable `Result`.
  - `LLM.py`: OpenAI-compatible client wrapper.
  - `tools.py`: Tool registry and `BaseTool`.
  - `camera.py`: Simple camera screenshot tool.
- Hardware and Vision Assistance:
  - `init.py`: Robotic arm initialization, gripper control, camera photography.
  - `eyeonhand.py`: Performs affine mapping from pixel coordinates to robotic arm coordinates based on calibration points in `config.json`.
  - `api.py`: Calls external vision services.
  - `utils/`: JetCobot configuration, ROI cropping, vision utility functions.
