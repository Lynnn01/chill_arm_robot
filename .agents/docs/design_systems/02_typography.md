# Principle 2: Typography (ระบบตัวอักษร)

## แนวคิดหลัก (Core Concept)
การจัดวางตัวอักษรที่ดีช่วยให้ผู้ใช้กวาดสายตาอ่านข้อมูล (Scanning) ได้อย่างรวดเร็วและเข้าใจโครงสร้างของเนื้อหา

## กฎการออกแบบจาก Awesome Design Systems
1. **Hierarchy (ลำดับชั้นของตัวอักษร):**
   - **Heading (หัวข้อ):** ขนาดใหญ่ หนา เพื่อดึงดูดสายตาและแบ่งหมวดหมู่ (เช่น H1, H2, H3)
   - **Body (เนื้อหาหลัก):** ขนาดมาตรฐาน (มักใช้ 14px - 16px) น้ำหนักปกติ เน้นความสบายตาในการอ่านยาวๆ
   - **Caption/Small (ข้อความรอง):** ขนาดเล็ก ใช้สำหรับคำอธิบายเพิ่มเติม หรือข้อความระบบที่ไม่สำคัญมาก
2. **Font Family (แบบอักษร):**
   - ควรใช้แบบอักษรที่ไม่มีหัว (Sans-serif) สำหรับ UI เพราะอ่านง่ายบนหน้าจอ
   - ไม่ควรใช้แบบอักษรเกิน 2 ตระกูลในหนึ่งโปรเจกต์ (เช่น 1 สำหรับหัวข้อ 1 สำหรับเนื้อหา)
3. **Line Height (ความห่างระหว่างบรรทัด):**
   - บรรทัดที่ติดกันเกินไปทำให้อ่านยาก โดยทั่วไป Line Height ควรเป็น 1.4 - 1.6 เท่าของขนาดตัวอักษร
4. **Weight & Color (น้ำหนักและสี):**
   - ใช้ความหนา (Bold) เพื่อเน้นจุดสำคัญ
   - ข้อความรองควรใช้สีเทา (Muted) แทนการลดขนาดอักษรเพียงอย่างเดียว เพื่อลดการรบกวนสายตา
