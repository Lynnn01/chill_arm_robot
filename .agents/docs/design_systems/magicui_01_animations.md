# Magic UI Principle 1: Micro-interactions & Animations (อนิเมชันขนาดเล็กและการโต้ตอบ)

## แนวคิดหลัก (Core Concept)
UI ที่ดีต้องไม่หยุดนิ่ง การเคลื่อนไหวเพียงเล็กน้อย (Micro-interactions) จะช่วยให้ผู้ใช้รู้สึกว่าระบบมีชีวิตชีวา ตอบสนองเร็ว และน่าใช้งานมากขึ้น

## กฎการออกแบบจาก Magic UI
1. **Instant Feedback (ตอบสนองทันที):**
   - เมื่อเมาส์ไปชี้ (Hover) ปุ่มหรือการ์ด ควรมีการขยายขนาดเล็กน้อย (Scale up) หรือสีสว่างขึ้นทันที เพื่อให้รู้ว่ากดได้
2. **Smooth Transitions (การเปลี่ยนผ่านที่นุ่มนวล):**
   - การเปลี่ยนแปลงสถานะทุกอย่าง (เช่น เมนูเลื่อนลงมา, กล้องเริ่มทำงาน) ไม่ควรเกิดขึ้นแบบกระตุกหรือหายไปในพริบตา ควรมีระยะเวลา Transition (เช่น 0.2 - 0.3 วินาที) ที่สมูท
3. **Purposeful Motion (เคลื่อนไหวอย่างมีความหมาย):**
   - อย่าใส่อนิเมชันเยอะเกินไปจนรกตา ทุกการเคลื่อนไหวต้องมีหน้าที่ เช่น ดึงดูดสายตาไปยังปุ่มสำคัญ หรือแสดงให้เห็นว่ากระบวนการกำลังทำงานอยู่
