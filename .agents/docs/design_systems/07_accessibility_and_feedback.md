# 07 - Accessibility & Feedback

## 1. Contrast & Readability (ความคมชัดและการอ่าน)
- ต้องผ่านเกณฑ์ WCAG อย่างน้อยระดับ AA เสมอ
- สีของตัวหนังสือที่อยู่บนปุ่มกด (เช่น ขาวบนเขียว หรือ ขาวบนแดง) ต้องมี Contrast ที่เพียงพอให้คนสายตาไม่ดีอ่านได้
- อย่าใช้สีเทาจางเกินไปกับข้อมูลที่ "จำเป็นต้องอ่าน (Critical info)" สงวนตัวหนังสือสีจางไว้สำหรับข้อความอธิบายเสริม (Helper text) เท่านั้น

## 2. Keyboard Navigation
- ทุกปุ่ม ทุกแท็บ ทุกช่องกรอกข้อมูล ต้องสามารถกดไล่เข้าถึงได้ด้วยปุ่ม `Tab` บนคีย์บอร์ด
- **Focus Ring:** เมื่อใช้คีย์บอร์ดเลื่อนมาโดนปุ่มใดๆ ต้องมีกรอบสว่าง (Focus ring) ล้อมรอบเสมอ (ใน Tailwind คือ `focus-visible:ring-2 focus-visible:ring-offset-2`)
- อย่าลบ Focus ring ทิ้งเพียงเพราะ "มันดูไม่สวย" 

## 3. Clear State Feedback (บอกให้รู้ว่าเกิดอะไรขึ้น)
- ทุกการกระทำที่มีผลกับระบบ (เช่น กดบันทึกข้อมูล) **ต้องมีสัญญาณตอบกลับเสมอ**
- สัญญาณตอบกลับอาจเป็น:
  - ปุ่มหมุนติ้วๆ (Loading spinner) ระหว่างรอ
  - กล่องแจ้งเตือน (Toast Notification) โผล่ที่มุมจอเมื่อทำงานสำเร็จ `t("Save success")`
  - กล่องแจ้งเตือนสีแดง (Toast Error) พร้อมข้อความที่อธิบายได้เข้าใจง่ายเมื่อเกิดข้อผิดพลาด
