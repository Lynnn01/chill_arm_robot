# 05 - Motion & Animations

## 1. Purposeful Animation (ขยับอย่างมีความหมาย)
- Animation ทุกตัวต้องมีเหตุผลรองรับ ไม่ใช่ใส่มาเพียงเพราะมัน "ดูเท่" 
- **แอนิเมชันที่ดีต้องช่วยชี้ทางผู้ใช้:** เช่น ลากสายตาไปที่ของใหม่ที่เพิ่งถูกสร้างขึ้นมา (Slide in), ย่อเก็บของที่ถูกลบ (Collapse & Fade out)
- หลีกเลี่ยงเอฟเฟกต์ที่เด้งดึ๋งมากเกินไป (Bouncy) ควรใช้จังหวะแบบ "เร็วตอนเริ่ม-ชะลอตอนจบ (Ease-out)" เพื่อจำลองแรงโน้มถ่วงในโลกจริง

## 2. Staggered Entries (การทยอยปรากฏ)
- ถ้าระบบต้องเรนเดอร์รายชื่อ (List) หรือกล่องการ์ดหลายๆ อันพร้อมกัน **อย่าให้มันโผล่มาพร้อมกันทีเดียวทั้งหมด**
- ให้ใช้เทคนิค **Stagger Animation** คือค่อยๆ ให้โผล่มาทีละอัน (ห่างกันทีละ 0.05 วินาที) พร้อมกับเอฟเฟกต์ Slide up + Fade in
- วิธีนี้ทำให้แอปรู้สึกเร็วขึ้น (Perceived Performance) เพราะหน้าตา UI เริ่มขยับตั้งแต่ข้อมูลตัวแรกมาถึง

## 3. Micro-interactions (การโต้ตอบจุดเล็กๆ)
- สอดแทรกแอนิเมชันในจุดเล็กๆ เช่น 
  - เวลาตัวเลข Profit/Loss อัปเดต ให้ตัวเลขกลิ้งเปลี่ยนค่าเหมือนมาตรวัด (Counter animation) แทนที่จะกระพริบแวบเปลี่ยนเลย
  - การเปิดปิด Modal (Popup) ควรมี Animation ขยายตัวขึ้นมาเล็กน้อย (Scale in)
- ในโค้ด มักจะใช้ไลบรารีอย่าง **Framer Motion** ร่วมกับ React เพื่อจัดการเรื่องนี้ได้อย่างนุ่มนวลที่สุด
