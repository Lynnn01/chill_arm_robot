# Principle 6: Affordance (ความชัดเจนในการใช้งาน)

## แนวคิดหลัก (Core Concept)
ผู้ใช้ไม่ควรต้องคิดว่า "สิ่งนี้กดได้ไหม?" หรือ "กล่องนี้กรอกข้อมูลได้ไหม?" การออกแบบที่ดีทำให้สิ่งเหล่านี้ชัดเจนโดยอัตโนมัติ

## กฎการออกแบบจาก Awesome Design Systems (อ้างอิงจาก IBM Carbon, Shopify Polaris)
1. **Button vs. Text (ปุ่มต้องดูเหมือนปุ่ม):**
   - ปุ่มที่กดได้ต้องมีกรอบ (Border) หรือพื้นสีที่แตกต่างจากข้อความธรรมดา เพื่อให้รู้ทันทีว่ากดได้
   - ข้อความที่เป็น Link ควรมีสีต่างออกไปหรือมีเส้นใต้ เพื่อแยกแยะจากข้อความปกติ
2. **Cursor Change (การเปลี่ยนรูปเคอร์เซอร์):**
   - เมื่อนำเมาส์ไปชี้บนสิ่งที่กดได้ เคอร์เซอร์ควรเปลี่ยนจากลูกศร (`default`) เป็นมือ (`pointer` / `hand2`) เพื่อสื่อสารว่า "กดได้"
3. **Input Fields (ช่องกรอกข้อมูลต้องชัดเจน):**
   - ช่องกรอกข้อมูลต้องมีเส้นขอบ (Border) หรือพื้นหลังที่ต่างออกไปอย่างชัดเจน เพื่อสื่อสารว่า "พิมพ์ได้ที่นี่"
   - การเพิ่ม Placeholder Text สีเทาจางๆ ภายในช่องช่วยบอกให้รู้ว่าควรกรอกข้อมูลอะไรลงไป
4. **Icon + Label (ไอคอนต้องมีคำอธิบาย):**
   - ไอคอนเพียงลำพังอาจตีความผิดได้ ควรมีข้อความกำกับ (Label) เสมอ โดยเฉพาะในส่วนที่ผู้ใช้ยังไม่คุ้นเคย
