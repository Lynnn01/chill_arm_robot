# Principle 4: Components and States (องค์ประกอบและสถานะ)

## แนวคิดหลัก (Core Concept)
ปุ่มและช่องกรอกข้อมูลต้องแสดงสถานะปัจจุบันให้ผู้ใช้รับรู้เสมอ เพื่อให้เกิดความมั่นใจในการใช้งาน

## กฎการออกแบบจาก Awesome Design Systems
1. **Interactive States (สถานะการโต้ตอบ):**
   - **Default:** สถานะปกติที่มองเห็นได้ชัดเจน
   - **Hover:** เมื่อนำเมาส์ไปชี้ ควรมีการเปลี่ยนแปลงเล็กน้อย (เช่น สีเข้มขึ้นหรืออ่อนลง) เพื่อบอกว่า "กดได้"
   - **Active/Pressed:** สถานะขณะถูกกด เพื่อให้ feedback ว่าระบบรับคำสั่งแล้ว
   - **Disabled:** เมื่อไม่สามารถใช้งานได้ ควรเปลี่ยนเป็นสีเทาและจางลง เพื่อไม่ให้เรียกร้องความสนใจ
2. **Consistency (ความสม่ำเสมอ):**
   - ปุ่มที่มีหน้าที่คล้ายกัน ต้องมีหน้าตาเหมือนกัน (เช่น ปุ่มยกเลิกทุกหน้าควรมีหน้าตาเป็นปุ่มใสขอบเทาเหมือนกันหมด)
3. **Ghost & Outline Buttons (ปุ่มรอง):**
   - ปุ่มที่ไม่ใช่ Action หลัก ไม่ควรใช้สีทึบ ควรใช้ปุ่มแบบมีแค่เส้นขอบ (Outline) หรือไม่มีขอบ (Ghost) เพื่อลดความโดดเด่นลง ให้ความสำคัญกับปุ่มหลัก (Primary Button) แทน
