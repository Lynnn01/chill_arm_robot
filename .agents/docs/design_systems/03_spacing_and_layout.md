# Principle 3: Spacing and Layout (ระยะห่างและการจัดวาง)

## แนวคิดหลัก (Core Concept)
Whitespace (พื้นที่ว่าง) ไม่ใช่พื้นที่ที่สูญเปล่า แต่เป็นองค์ประกอบสำคัญที่ช่วยแยกแยะเนื้อหาและทำให้ UI ดูไม่อึดอัด

## กฎการออกแบบจาก Awesome Design Systems
1. **8-Point Grid System (ระบบกริดฐาน 8):**
   - ระยะห่าง (Margin, Padding) ควรเป็นพหุคูณของ 8 (เช่น 8px, 16px, 24px, 32px) เพื่อให้ทุกส่วนสอดคล้องและเป็นระเบียบ
2. **Proximity (ความใกล้ชิด):**
   - สิ่งที่เกี่ยวข้องกัน ต้องอยู่ใกล้กัน (เช่น ป้ายกำกับ Label ควรอยู่ติดกับช่องกรอกข้อมูล Input)
   - สิ่งที่ไม่เกี่ยวข้องกัน ต้องถูกแยกออกจากกันด้วยพื้นที่ว่างที่กว้างกว่า
3. **Card-based Interface (การใช้การ์ด):**
   - การรวบรวมข้อมูลที่เกี่ยวข้องไว้ใน "การ์ด" (กรอบที่มีเส้นขอบบางๆ หรือพื้นหลังสีต่างจากพื้นหลักเล็กน้อย) ช่วยให้ผู้ใช้แยกแยะกลุ่มข้อมูลได้ง่ายขึ้น
4. **Alignment (การจัดแนว):**
   - จัดแนวเนื้อหาไปในทิศทางเดียวกัน (มักจะจัดชิดซ้ายสำหรับการอ่านทั่วไป) เพื่อสร้างเส้นนำสายตาที่เป็นระเบียบ
