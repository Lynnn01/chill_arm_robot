# 03 - Spacing & Layout (Grid & Bento)

## 1. Grid-Based Spacing (ระบบระยะห่างที่เป็นสัดส่วน)
- ระยะห่างทั้งหมด (Padding, Margin, Gap) ต้องอิงจากระบบ 4px หรือ 8px เสมอ (ใน Tailwind คือ `1, 2, 4, 8, 16, 24` เป็นต้น)
- ห้ามใช้ตัวเลขประหลาด (เช่น 13px หรือ 17px) เด็ดขาด เพื่อให้ทุกหน้าจอมีความเป็นระเบียบ (Rhythm) ที่ตรงกัน
- **ความกว้างสูงสุด (Max Width):** ควบคุมความกว้างของเนื้อหาไม่ให้ยาวเต็มจอเกินไป (เช่น ใช้ `max-w-7xl mx-auto`) เพื่อรักษาบรรทัดให้อ่านง่าย

## 2. Bento Grid Pattern
- ออกแบบ Layout ในลักษณะเป็น **Bento Box** (กล่องสี่เหลี่ยมหลายๆ ขนาดมาเรียงต่อกัน) ซึ่งเข้ากับสไตล์ Modern & Glassmorphism ได้ดีมาก
- กล่องแต่ละใบ (Card) ควรมีขอบมน (Border radius) และระยะห่างรอบตัวที่ชัดเจน `gap-4` หรือ `gap-6`
- การใช้ Bento Grid ทำให้ UI ดูสนุกขึ้น ไม่น่าเบื่อเหมือน List เรียงลงมาตรงๆ และสามารถย่อขยายรองรับ Responsive (Mobile/Desktop) ได้ง่ายมาก

## 3. Visual Impact Layout
- **Hero Section:** ส่วนบนสุดของแอป ต้องดูมีพลัง สื่อสารชัดเจน ใช้ฟอนต์ขนาดใหญ่ มีปุ่ม CTA (Call to Action) ที่สะดุดตา
- การจัดวางต้องมี **Negative Space (พื้นที่ว่าง)** เยอะๆ ไม่ต้องพยายามยัดเยียดข้อมูลทุกอย่างให้เต็มหน้าจอ "น้อยแต่มาก" (Whitespace is your friend)
- จัดกลุ่มข้อมูลที่เกี่ยวข้องกันไว้ด้วยกัน (Proximity Principle) และแยกข้อมูลคนละกลุ่มด้วยพื้นที่ว่างที่กว้างขึ้น
