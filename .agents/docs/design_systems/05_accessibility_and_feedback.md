# Principle 5: Accessibility and Feedback (การเข้าถึงและการตอบสนอง)

## แนวคิดหลัก (Core Concept)
ระบบควรสื่อสารกับผู้ใช้อยู่เสมอว่าเกิดอะไรขึ้น เพื่อไม่ให้ผู้ใช้รู้สึกสับสนหรือสูญเสียการควบคุม

## กฎการออกแบบจาก Awesome Design Systems
1. **System Feedback (การตอบสนองของระบบ):**
   - เมื่อผู้ใช้กดปุ่ม หรือสั่งการ ควรมีการตอบสนองทันที (เช่น แสดง Loading spinner, เปลี่ยนข้อความปุ่มเป็น "กำลังโหลด...")
   - แสดงข้อความสำเร็จ (Success) หรือข้อผิดพลาด (Error) อย่างชัดเจน พร้อมคำแนะนำว่าต้องทำอย่างไรต่อไป
2. **Clear Language (ภาษาที่เข้าใจง่าย):**
   - ใช้ข้อความที่กระชับ ตรงไปตรงมา (เช่น ใช้คำว่า "ส่งข้อความ" แทนคำว่า "ดำเนินการ")
   - หลีกเลี่ยงภาษาทางเทคนิค (Jargon) ในข้อความแจ้งเตือนที่ผู้ใช้ทั่วไปต้องอ่าน
3. **Contrast Ratio (อัตราส่วนความเปรียบต่าง):**
   - ตัวอักษรและพื้นหลังต้องมีความต่างของสีที่มากพอ (ตามมาตรฐาน WCAG) เพื่อให้ผู้ที่มีปัญหาทางสายตาสามารถอ่านได้ง่าย
4. **Error Prevention (การป้องกันข้อผิดพลาด):**
   - ปุ่มที่อาจทำให้เกิดความเสียหาย (เช่น Reset, Delete) ควรมีสีแดง (Danger) และจัดวางให้ห่างจากปุ่มปกติ เพื่อป้องกันการเผลอกด
