# .agents Directory

This directory contains configuration, rules, and skills for AI agents working on this project. 
It follows the standard agent configuration structure.

- `AGENTS.md`: The main index and critical rules.
- `rule/`: Detailed, categorized markdown rules (e.g. style, structure, env).
- `agents/`: Custom subagents defined for this specific project.
- `skills/`: Custom skills defined for this specific project.
